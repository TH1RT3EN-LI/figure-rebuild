# 细节修复与验证进度

[冻结的 126 图审查](2026-10-03-detail-audit.md)记录了修复前的 296 项问题。这份记录区分通用实现修复、真实输出验证和逐图问题关闭；实现测试通过不等于整批图已通过验收。

## 已实现的通用变化

- 文字首行基线使用实际渲染器字体度量，明确区分默认行距与精确行距，保留源 anchor、文本框、对齐和旋转中心。字号先按 PPT 精度舍入，原生上下 inset 等量反向校准。
- 图片保留默认 `contain`，增加显式 `stretch`；裁剪始终相对于完整素材，修复 SVG 裁后内容泄漏到留白的问题。PDF 图片提取保留实际绘制实例、完整变换、矩形裁剪、软蒙版和翻转，拒绝无法精确表示的效果。
- PDF outlined SVG 的路径和字形按实际资源引用与绘制顺序提取，保留精确 Bezier 和来源记录；不再通过最近坐标猜字形。轮廓转换须显式选择，不能称作可编辑文本框。
- 路径可显式写入原生 cap、join 和 miter limit。实际测试同时发现 Artifact Tool 2.8.59 的导入预览忽略这些属性；因此回执明确要求应用验证，不能据此称视觉问题已关闭。
- 诊断增加独立于输出对象的全源画布网格，记录原始误差、缩放、预算遗漏和请求范围。超大对象不再阻断后续小对象的检查。
- 源文字和有向连接可用 `source_evidence` 约束；无证据时明确为 `NOT_PROVIDED`。输出审查通过 `review-output` 绑定本次源图、清单、PPT 和预览，拒绝把旧报告套到新文件。

## 已完成验证

438 项 Python 测试通过（7 项因可选环境跳过），36 项 Node 测试通过；wheel 与源码包检查通过。另单独执行了真实导出回归，并保留外部证据和失败前记录：

- 原 36 个文字探针的最大偏移从 7.5 源像素降到 0.25 源像素。
- 160 个实际导出案例覆盖多行、两种缩放、旋转和垂直对齐。4x 采样中，墨迹边界与独立的已知物理基线参考一致；这不是对任意字体、后端或整张图的像素一致保证。
- 8 个图片实例保留原素材 SHA、裁剪和框坐标，包括重复资源、分数框及窄长图片。PDF 中原来被误缩小的 34×236 素材，4 个沿可见细条的采样点与源 PDF 高倍率渲染逐通道一致。
- 首批 5 张旧清单重新构建并实际复查，未观察到新增渲染回归；其中 TTT 的省略号定位问题从约 4.5 px 降至 0.5 px，关闭该条局部问题。其余 12 条被检查的旧问题保持开放。
